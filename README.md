# tfg_signals

## Trabajo de Fin de Grado: Aplicación de Voissnet a Señales Sísmicas Volcánicas de Tenerife

Este repositorio contiene el trabajo de fin de grado sobre la aplicación de [Voissnet](https://github.com/darren-tpk/voiss-net) a señales sísmicas volcánicas de Tenerife.

## Documentación

- [📅 Planificación Temporal](PLANIFICACION_TEMPORAL.md) - Planificación detallada del proyecto de Octubre 2025 a Junio 2026

## Descripción del Proyecto

El objetivo de este TFG es aplicar la arquitectura de red neuronal Voissnet para la clasificación y análisis de señales sísmicas volcánicas procedentes de las estaciones de monitoreo de Tenerife.

### Fases del Proyecto

1. **Familiarización y Fundamentos** (Octubre - Noviembre)
2. **Procesamiento y Análisis de Datos** (Diciembre - Enero)
3. **Adaptación e Implementación de Voissnet** (Febrero - Marzo)
4. **Evaluación y Experimentación** (Abril)
5. **Documentación y Redacción** (Mayo - Junio)
